# electron-learn

> 基于 Vue 3.5 + Electron 的跨平台 AI 桌面聊天应用

## 📝 项目简介

这是一个使用现代化技术栈构建的 Electron 学习项目，旨在创建一个功能丰富的跨平台桌面聊天应用程序，集成 AI 大模型能力。

## 🚀 技术栈

- **Vue 3.5** - 渐进式 JavaScript 框架
- **Electron** - 跨平台桌面应用开发框架
- **大模型集成** - AI 能力支持
- **TypeScript** - 类型安全的 JavaScript 超集

## 🎯 项目特点

- 💬 实时聊天功能
- 🤖 AI 大模型集成
- 🖥️ 跨平台支持 (Windows/macOS/Linux)
- 🌟 现代化 UI 界面
- 🛠️ 桌面应用特性

## 📦 开始使用

```bash
# 克隆项目
git clone https://github.com/your-username/electron-learn.git

# 进入项目目录
cd electron-learn

# 安装依赖
npm install

# 启动开发环境
npm run start
